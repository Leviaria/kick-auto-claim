# Kick Auto-Claim 1.0.1

Chrome extension for claiming eligible daily rewards, event rewards and drops on Kick.

Download `kick-auto-claim-1.0.1.zip`, extract it and load the folder from `chrome://extensions` using Developer mode and Load unpacked. Reload your Kick tabs after installation.

This version includes a simpler popup and GitHub installation instructions. No build step or separate account is needed.

Local mocked tests pass. Live authenticated claims are not yet verified; this release is a preview. Keep a signed-in Kick tab open. Updates must be installed manually.
